# 完了条件（G1〜G9）

[concept.md](concept.md) の「現状とのギャップ」G1〜G9 を、すべて達成したと言える条件。
**ここに書いた条件を満たしたら止める**（ここに無い改善は完了に含めない）。

## 読み方

- **確かめ方** は 3 種類
  - **自動**: `npm test` の中のテストで確かめる。LLM は偽物（`test/helpers/fake-llm.js`）を使うので、AI に届いた文と呼び出し回数も確かめられる
  - **PC**: この PC で、実データ（`data/`）と実際に設定しているローカル LLM を動かして確かめる。結果は PR 本文に書く
  - **人**: 人間がスマホや目で確かめる（AI だけでは確かめられない）
- **状態** の列は、初めは `未`。満たしたら `済 #<PR 番号>` にする。人の行は `人・未` → `人・済`
- 件数・回数などの数値は既定値。変えるときは、先にこの文書を直してから作る
- G の節は、[concept.md](concept.md) の「進める順番の目安」と同じ作る順（G1・G2 → G5 → G7 → G6 → G3・G4 → G8・G9）に並べている。2 つの G にまたがる部分は、**後に作る方**の条件に入れている

## すべて達成した状態

次の 4 つがすべて成り立ったとき、G1〜G9 を達成したとする。

1. 状態が `未` の行が 1 つも無い（`grep -cE '^\| G[0-9]-[0-9]+ \|.*\| 未 \|' docs/done-criteria.md` の出力が 0。このとき grep 自体は終了コード 1 を返す）
2. 状態の列に書いた PR が、すべて main にマージ済み（`gh pr view <番号> --json state` が `MERGED`）
3. 最新の main で `npm test` が終了コード 0、CI が成功
4. 人の行がすべて `人・済`、[concept.md](concept.md) の「足りないもの」が空
